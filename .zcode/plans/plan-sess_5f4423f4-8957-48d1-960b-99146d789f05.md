## 版本号升级计划：1.5.1 → 2.0.0

经过全面审计，需要修改版本号的文件共 **4 个**。版本号在前端代码中通过 `getVersion()`（Tauri API）运行时读取，没有硬编码版本字符串，因此只需改配置文件。

### 需要修改的文件

| # | 文件 | 行号 | 当前值 | 修改为 |
|---|------|------|--------|--------|
| 1 | `package.json` | 4 | `"version": "1.5.1"` | `"version": "2.0.0"` |
| 2 | `src-tauri/Cargo.toml` | 3 | `version = "1.5.1"` | `version = "2.0.0"` |
| 3 | `src-tauri/tauri.conf.json` | 4 | `"version": "1.5.1"` | `"version": "2.0.0"` |
| 4 | `src-tauri/Cargo.lock` | 1173 | `version = "1.5.1"`（`easy_agent_pilot` 包条目） | `version = "2.0.0"` |

### 无需修改的地方（已确认）

- **自动更新配置**（`tauri.conf.json` 的 updater 块）：不含版本号，通过 GitHub Release `latest.json` 运行时获取，版本由 Git tag 驱动
- **前端源码**（`.ts`/`.vue`）：版本号通过 `getVersion()` 从 Tauri 运行时读取，无硬编码
- **i18n 文件**（`zh-CN.ts`/`en-US.ts`）：使用 `v{version}` 占位符，运行时注入
- **CI 发布工作流**（`.github/workflows/release.yml`）：使用 `${{ github.ref_name }}`（Git tag），不硬编码版本
- **`tauri.ci.conf.json`**：无 version 字段
- **测试文件中的版本号**（`mockUpdaterAdapter.ts`、`appUpdate.test.ts`、`useAppBootstrap.ts` DEV hooks）：是 mock 测试数据（`'1.2.1'` 等），与实际版本无关
- **pnpm-lock.yaml 中的 `1.5.1`**：是 `base64-js@1.5.1` 依赖版本，不是应用版本

### 执行步骤

1. 修改上述 4 个文件的版本号
2. 运行 `pnpm typecheck` + `cargo check` 验证无错误
3. 使用 Tauri MCP 启动应用，确认设置页更新检查中显示 `v2.0.0`
